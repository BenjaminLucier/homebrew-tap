# BenjaminLucier/homebrew-tap

Homebrew formulas for my projects.

```sh
brew install BenjaminLucier/tap/<formula>
```

| Formula | Project |
|---------|---------|
| `anzan` | [A terminal trainer for mental math](https://github.com/BenjaminLucier/anzan) |

The formulas are updated automatically by each project's release workflow.
